# Reference projects

This project independently implements a narrow desktop extension after studying:

- CodexPlusPlus, Copyright (C) 2026 BigPizzaV3, AGPL-3.0-only.
  https://github.com/BigPizzaV3/CodexPlusPlus
  Reference commit: 693c8486bafb0f98e2539c455335d3d2fd42ce00.
  Referenced concepts: CDP launcher, sidebar DOM attributes and confirmation interaction.
- OpenAI Codex, Apache-2.0.
  https://github.com/openai/codex/tree/rust-v0.151.0
  Referenced interfaces: thread/read, thread/list and thread/delete.

No OpenAI desktop binaries or extracted application assets are distributed in this package.
OpenAI, Codex and ChatGPT names identify the compatible application; this is an unofficial extension.
